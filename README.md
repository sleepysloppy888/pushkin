# Пушкинская читальня

Учебный сайт на основе библиотеки-читальни имени А. С. Пушкина в Москве.

## Как открыть

Дважды нажмите `index.html`. Рядом должны оставаться остальные файлы и папки из архива. Сайт работает без установки программ. Тексты, фотографии и jQuery включены в проект; при отсутствии интернета используется системный шрифт.

## Что работает

- Каталог из 30 книг, поиск по названию и автору, фильтры жанра, года и фонда.
- Подробные аннотации по нажатию на обложку или название.
- Регистрация, вход, бронирование, отмена, возврат и однократное продление на 7 дней.
- Рекомендации по выбранным интересам и история возвратов.
- Читалка с 9 полными текстами: «Евгений Онегин», «Капитанская дочка», «Повести Белкина», «Руслан и Людмила», «Медный всадник», «Борис Годунов», «Сказка о царе Салтане», «Герой нашего времени», «Вишнёвый сад».
- Оглавление, переход к странице, размер шрифта и сохранение страницы чтения.
- Три темы: светлая, тёплая и тёмная. Адаптивная вёрстка для телефона.
- Ссылки подвала на разделы, контакты, телефон, почту, карту и официальный сайт.

## Администратор

Откройте **Кабинет → Открыть демо-админку**. Также можно войти обычным способом: `admin@pushkin.ru`, пароль `admin`.

Администратор видит пользователей и брони этого браузера, принимает возвраты, меняет число доступных экземпляров и загружает полный текст выбранной книги (TXT в UTF-8, до 2 МБ). Используйте файлы, которые разрешено включать в проект.

Чтобы добавить загруженные тексты в общую версию сайта, нажмите **Скачать books.js для публикации** и замените файл `books.js` в проекте скачанным файлом.

## Ограничения учебной версии

Данные хранятся в localStorage конкретного браузера. Это демонстрация без общего сервера: брони не отправляются в настоящую библиотеку, а аккаунты не синхронизируются между устройствами. Для реального многопользовательского сервиса нужны серверная авторизация, PHP и MySQL. Демонстрационная админка не является защищённой серверной админкой. Напоминания отображаются в кабинете; отправки писем и SMS нет. Защита DRM не реализована.

У современных книг без предоставленного полного текста кнопка чтения не показывается. Одного и того же демонстрационного отрывка вместо разных книг больше нет. Оригинальный год и названия некоторых учебных карточек сохранены из исходника; данные фонда и афиши демонстрационные.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий, например `pushkin`.
2. Распакуйте архив и загрузите **всё его содержимое**, сохранив папки `assets` и `vendor`. Файл `index.html` должен находиться в корне репозитория.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь ссылки в разделе Pages. Обычно она имеет вид `https://ВАШ-ЛОГИН.github.io/pushkin/`.

GitHub Pages публикует статические файлы и не запускает PHP или MySQL. Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Для доработки

- `index.html` — разделы сайта.
- `base.css` — стили исходного макета; `styles.css` — обновлённый дизайн.
- `app.js` — каталог и основные сценарии; `enhancements.js` — карточки, читалка, навигация и админка.
- `descriptions.js` — подробные аннотации; `books.js` — полные тексты.
- `assets/` — фотографии; `vendor/jquery.min.js` — локальная зависимость.
- `SOURCES.md` — источники фотографий, контактов и произведений.

При установленном Node.js можно запустить `node scripts/preview.mjs` и открыть `http://127.0.0.1:4173`. Проверка данных и пагинации: `node scripts/check.mjs`.
